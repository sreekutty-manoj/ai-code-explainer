# AI Code Explainer

A beginner-friendly AI application built with Python, Django REST Framework, and Ollama. It accepts Python code and generates a simple explanation using a locally running AI model.

## Features

- Accepts Python code through a REST API.
- Generates explanations using a local AI model.
- Validates empty and whitespace-only input.
- Handles connection errors and timeouts.
- Includes automated API tests.

## Technologies

- Python
- Django
- Django REST Framework
- Ollama
- Qwen2.5 0.5B
- Requests

## Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd ai_learning
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the URL of your repository.

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
pip install -r requirements.txt
```

### 4. Install and start Ollama

Install Ollama, then download the model:

```powershell
ollama pull qwen2.5:0.5b
```

Ensure Ollama is running before calling the API.

### 5. Prepare the Django database

```powershell
python manage.py migrate
```

### 6. Start the development server

```powershell
python manage.py runserver
```

## API Endpoint

**Method:** POST

**Endpoint:** `/api/explain/`

Example request:

```json
{
  "code": "print(2 + 3)"
}
```

The response contains the submitted code and an explanation generated by the local model.

## Run Tests

```powershell
python manage.py test code_explainer
```

## Notes

- Ollama must be installed and running locally.
- The model may generate inaccurate explanations; verify important results.
- This project is intended for learning and local development.
